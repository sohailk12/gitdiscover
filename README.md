# GitDiscover 🔍

A web app built with **React + Vite** that helps users explore GitHub repositories easily.  
It provides a clean interface to search, filter, and view project details.

---

## 🚀 Features
- Search GitHub repositories by name
- View repository details (name, stars, language, etc.)
- Responsive UI with modern design
- Built using React + Vite for fast performance

---

## 🛠️ Tech Stack
- **Frontend:** React, Vite
- **Styling:** Tailwind CSS (if you used it)
- **API:** GitHub REST API
- **Other Tools:** Axios / Fetch
